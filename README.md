# GCHX-Based Air-Conditioning System
**Performance Study & Thermal Verification for Microclimate Control (Mushroom Cultivation)**

## Overview
This repository contains the technical verification report and experimental Data Acquisition System (DAQ) logs for a Ground-Coupled Heat Exchanger (GCHX) and auxiliary cooling tower system designed for a precision microclimate chamber ($3.0\text{ m} \times 3.0\text{ m} \times 2.5\text{ m}$).

## Key Operational Parameters
* **Target Application:** Controlled environment agriculture ($A. \text{bisporus}$ / $\text{Pleurotus spp.}$ cultivation).
* **Winter Operational Benchmark:** $18.0^\circ\text{C} \pm 0.5^\circ\text{C}$ via sub-surface GCHX loop ($2.5\text{ m}$ depth).
* **Summer Operational Benchmark:** $26.0^\circ\text{C} \pm 0.5^\circ\text{C}$ via auxiliary copper coil and evaporative cooling loop.
* **Relative Humidity:** Maintained at a constant $70\% \pm 3\%$ RH via ultrasonic humidification and feedback control.
